# FaithNotes AI

FaithNotes AI is an AI-powered sermon companion for recording sermons, live transcription, Bible-verse detection, AI study aids, sermon chat, prayer journaling, and a personal Bible verse library.

## Project structure

- `public/faithnotes-ai.html` — self-contained frontend
- `backend/` — Node/Express API with SQLite
- `dev-server/` — local development server
- `.github/workflows/` — CI and GitHub Pages configuration
- `docs/` — architecture, deployment, security, database, transcription, and AI documentation

## Important

This repository is **FaithNotes AI** and is intended for `RoyalFinTech/FaithNoteAi`.
